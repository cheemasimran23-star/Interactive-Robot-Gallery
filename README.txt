ROBOT GALLERY

The six photographs supplied for this project are included in this images
folder as robot-1.jpg through robot-6.jpg. Keep this folder beside
index.html, style.css and script.js. The HTML uses local image paths.

TESTING
1. Open the project folder in Visual Studio Code.
2. Open index.html in a browser (or use Live Server).
3. Hover over each image and move the pointer away.
4. Press Tab to focus each figure; the large preview should update.
5. Press Tab again; blur should reset the preview.
6. Check the browser console for event messages.
7. Validate with W3C and test accessibility with WAVE and axe.

The photographs were supplied by the user. Confirm you have permission to
publish them if you put the website online.
